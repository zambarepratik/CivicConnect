# Public Grievance & Redressal Backend

Express.js and Supabase backend with JWT-based role authentication (`user`, `officer`, `super_admin`).

---

## Prerequisites
* Node.js (v18 or higher)
* Git

---

### 1. Clone & Install Dependencies
